Algoritmo de Decisão

Como o SoilSniff interpreta os dados dos sensores e classifica a saúde do solo

Voltar para o início
// Pseudocódigo — Algoritmo SoilSniff v1.0

1. Ler sensor_amonia (MQ-135)
2. Ler sensor_metano (MQ-4)
3. Ler sensor_sulfeto (MQ-136)
4. Ler umidade_solo (higrômetro)

5. SE umidade_solo < 20%:
    → LED = 🔴 VERMELHO // Solo muito seco

6. SENÃO SE umidade_solo > 80%:
    → LED = 🔴 VERMELHO // Solo encharcado

7. SENÃO SE metano > 30ppm OU sulfeto > 5ppm:
    → LED = 🔴 VERMELHO // Solo doente

8. SENÃO SE amonia > 5ppm E amonia < 50ppm:
    → LED = 🟡 AMARELO // Atenção necessária

9. SENÃO:
    → LED = 🟢 VERDE // Solo saudável
20–80%
Umidade ideal
Fora disso → vermelho imediato
5–50ppm
Amônia (atenção)
Decomponsição aeróbica ativa
<30ppm
Metano (seguro)
Acima → solo compactado
<5ppm
Sulfeto (seguro)
Acima → putrefação detectada

💻 Código Arduino — Função de Classificação

/*
 * classificarSolo()
 * Retorna: 0 = Verde, 1 = Amarelo, 2 = Vermelho
 */
int classificarSolo() {
  // Estresse hídrico severo (solo seco)
  if (umidade < 20.0) return 2;

  // Solo encharcado
  if (umidade > 80.0) return 2;

  // Gases tóxicos — solo doente
  if (metano > 30.0 || sulfeto > 5.0) return 2;

  // Matéria orgânica em decomposição
  if (amonia > 5.0 && amonia < 50.0) return 1;

  // Solo fértil e saudável
  return 0;
}
