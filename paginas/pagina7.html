Como Contribuir

O SoilSniff é open-source e open-hardware — toda ajuda é bem-vinda!

Voltar para o início
Este é um projeto aberto criado para ajudar pequenos agricultores do sudoeste do Paraná. Acreditamos que tecnologia de qualidade não pode ser privilégio de grandes produtores. Se você tem conhecimento, dados de campo, ou só quer torcer — você já faz parte disso.

🌽 “Por uma agricultura acessível a todos os produtores.”

Capanema-PR, Sudoeste do Paraná
🧪

Dados de Campo

Envie amostras de solo ou padrões de leitura da sua região para calibrar o algoritmo e aumentar a precisão do sistema.

💻

Código

Melhore o algoritmo de decisão, adicione suporte a novos sensores, otimize o consumo de energia da bateria.

🔧

Hardware

Sugira componentes mais baratos, projetos de PCB personalizada, ou formas de reduzir o custo de fabricação em série.

📝

Documentação

Traduza para outros idiomas, crie tutoriais em vídeo ou escreva guias de montagem mais simples para leigos.

🗣️

Divulgação

Compartilhe com outros agricultores, escolas técnicas, universidades e cooperativas agropecuárias da região.

🐛

Reportar Bugs

Encontrou um erro no código ou na documentação? Abra uma issue no GitHub e nos ajude a melhorar.

🐙 Ver no GitHub

Todo o código, esquemas de hardware e documentação estão disponíveis livremente sob a licença MIT. Qualquer pessoa pode usar, modificar e distribuir.
